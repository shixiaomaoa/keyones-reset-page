# keyones-reset-page

心意管家（keyones-app）的公网密码重置页：Supabase Auth「忘记密码」邮件中的链接指向这里，用户在页面上用邮件携带的一次性 `token_hash` 换取会话并设置新密码。

- 单个零依赖 `index.html`（原生 HTML/CSS/JS，无构建、无 CDN）
- 托管：GitHub Pages
- 页面地址：<https://shixiaomaoa.github.io/keyones-reset-page/>

页面源码的权威副本在主仓库 `web/reset-password/index.html`；修改后同步到本仓库并推送即完成部署。
